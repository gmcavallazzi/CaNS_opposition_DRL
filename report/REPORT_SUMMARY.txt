================================================================================
THEORETICAL HIGHLIGHTS
================================================================================

1. MARKOV PROPERTY PRESERVATION
   Theorem: The augmented state s_t = [u_t, w_t, a_{t-1}] preserves the
   Markov property because a_{t-1} becomes part of the next state.

2. TEMPORAL COUPLING
   Theorem: With action memory, current action choice a_t directly affects
   future state representation, creating temporal consistency incentive.

3. CRITIC REDUNDANCY IS NECESSARY
   Theorem: Critic must receive both full state (including a_{t-1}) and
   current action (a_t) for proper Q-function approximation Q(s, a).

4. ADAPTIVE vs FIXED FILTERING
   Action memory enables learned adaptive filtering:
     α_learned(u_t, w_t) instead of fixed α
   Policy learns WHEN to smooth and WHEN to respond quickly.
